# IEP 목업 전달 메모

2026-09-23 · 유아특수교사 중심의 주·월 실행 계획

## 확인 순서

1. `careit-mockup.html`에서 왼쪽 IEP를 선택합니다.
2. 첫 번째 대상에 미리 입력된 합성 예시를 확인하고 **계획 초안 만들기**를 누릅니다.
3. 현행수준, 교육목표, 관련 누리과정, 교육내용·방법, 평가계획, 평가결과의 7개 항목을 확인합니다.
4. **구성 근거**를 눌러 자료의 원칙과 적용 내용을 확인합니다.
5. **내용 수정**으로 편집하고 **검토 완료하고 저장**합니다.
6. **평가결과 기록**에서 실제 관찰을 기록합니다. 관찰 전에는 비워 두고 저장할 수 있습니다.
7. **저장한 계획**에서 다시 열거나 **계획서 보기**로 표를 확인합니다. **계획서 내려받기**로 HTML 문서를 받고 브라우저 인쇄에서 PDF로 저장할 수 있습니다.

새 대상은 빈 양식에서 시작합니다. **예시 불러오기**로 동일한 합성 사례를 살펴볼 수 있습니다. 작성 중인 초안을 바꾸거나 새 계획을 시작할 때는 앱 안에서 변경 확인을 합니다.

## 반영한 디자인

- 기존 본문 폭, Pretendard, 회색 입력칸, 초록 배지, 카드 그림자와 반경 재사용
- 안내 14px, 입력·결과 본문 16px, 섹션 제목 20px
- 목표 입력 / 계획 검토 / 저장 단계 표시
- 검토 전·검토 완료 상태 구분; 저장한 결과를 수정하면 검토 전으로 전환
- 달력과 대상 선택 팝업은 기존 공통 컴포넌트 사용
- 작은 화면에서는 2열 목표·관찰 입력을 1열로 배치

## 자료와 결과의 경계

`iep.js`의 현재 구성 근거는 특수교육법 시행규칙 제4조, 유치원 교육과정 고시 제2019-189호, 자체 작성 규칙과 합성 예시입니다. 기존 업무길라잡이·해설서·DEC는 신규 구성에서 제외했으며, 이전 결과는 당시 참고 이력으로 구별합니다. 전체 결정 및 이용조건 근거는 `IEP-SOURCE-LICENSES.md`를 참고하세요.

기본 예시의 목표·관찰·활동·지원·평가 문장은 합성 입력입니다. 출력은 이 입력과 자료의 원칙을 연결한 UI 검토용 계획입니다. 실제 아동 분석·목표 적합성 검증·AI·RAG·서버 저장은 구현하지 않았습니다. 공식 IEP 확정 절차와는 구분합니다.

## 실행 확인

- JavaScript 문법 검사 및 단일 HTML 빌드 성공
- 목표 입력에서 계획 초안 구성, 결과 편집·저장, 새로고침 복원
- 입력 수정 후 직접 편집한 연결 문장 유지
- 저장 목록에서 재열기; 관리대상 전환 시 계획 목록 분리
- 필수 항목 누락 시 브라우저 검증 안내
- IEP 10월 미래 기간 선택 및 월·주 기간 불일치 안내
- 기존 기록 달력의 미래 날짜 제한 유지
- 자료 근거 팝업 열기·닫기
- 390px 화면의 가로 넘침 없음 및 입력·결과 반응형 배치 확인
- 표 형식 HTML 내려받은 파일의 7개 구분, 목표·결과·근거 링크 확인
- 수정본 HTML에 IEP 데이터·코드·스타일 포함, 내보낸 파일 재실행 후 저장 결과·직접 편집한 문장 복원

검수한 전달 HTML과 소스가 ZIP에 포함됩니다. `_qa`, 서버 로그, 브라우저 검수 데이터는 ZIP에서 제외합니다.

## 이전 버전의 양식 반영 검수 이력

- 이전 양식의 초안·저장본을 `schemaVersion:2`로 변환하고 기존 문장·날짜·저장 ID 유지
- 직접 수정했던 목표 연결과 자료 문구가 입력 재반영 후에도 유지됨
- 교육방법에 준비·환경, 진행 순서, 교사 지원, 반응별 지원 표시
- 평가방법·평가초점 분리, 빈 실제 관찰 저장 가능
- 실제 관찰 입력 → 저장 → 저장 목록 → 다시 열기 확인; 검수 문구는 비움
- 카드/표 전환, 인천교육청 양식 근거 팝업 확인
- 모바일 390px에서 본문 넘침 없음; 넓은 계획서 표는 전용 영역 안에서 가로 스크롤
- 새로고침 후 저장 상태와 빈 평가결과 복원

## 개인정보 최소 입력 반영

대상 구분명·연령대만 등록하며 자유 메모는 신규 수집하지 않습니다. 기존 데이터는 보존합니다. IEP 선택 입력, 계획 구성용 정보 확인, 허용 목록과 v2→v3 보존 검사 결과는 `IEP-MINIMUM-DATA.md`를 참고하세요. 실제 AI 전송과 자동 익명화는 없는 목업입니다.


## 2026-09-23 자료 사용 범위 조정

- 법령·고시 원문과 자체 작성 예시만 신규 구성에 연결합니다.
- 이전 저장본은 원래 출처·문장·검토 상태를 보존하고 신규 자료로 검증됐다고 표시하지 않습니다.
- 이전 자료의 설명 요약을 제거했고, 필요한 참고 이력만 남깁니다.
- 사용 조건·보류 이유·대체 범위·관리 작업의 의미는 `IEP-SOURCE-LICENSES.md`에 정리했습니다.

검증: JavaScript 문법/단일 HTML 빌드, 개인정보 허용 목록 및 v2 데이터 보존 검사, 신규 출처 제한과 이전 출처/편집/상태 보존 및 다운로드 검사 통과. 실제 브라우저에서 신규 구성 근거 목록·고시 팝업·공식 링크 표시를 확인했고 JavaScript 오류가 없었습니다.
