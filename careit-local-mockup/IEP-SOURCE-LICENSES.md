# IEP 자료 이용조건 확인 및 채택 기준

확인일: 2026-09-23. 적용: 케어릿 유아특수교사 중심 월간 실행 계획 목업.

## 결정

신규 계획에는 **특수교육법 시행규칙 제4조, 유치원 교육과정 고시 원문, 교사 입력 및 자체 작성 규칙/합성 예시**를 사용한다. 인천교육청 업무길라잡이, 특수교육 교육과정 해설서, DEC 원문·번역·활동 예시는 신규 구성 자료에서 제외한다. 해당 자료 이용료를 견적에 추가하거나 권리자에게 허가 요청을 보내지 않았다.

이는 보호되는 자료를 바꿔 써서 제한을 우회하는 방식이 아니다. 이용 근거가 확인된 원문과 자체 콘텐츠를 선택하는 방식이다. 명칭·출처만 바꾸면 기존 저작물의 이용 문제가 해소되는 것은 아니다. 일반적인 교육 원리와 기능상 필요한 항목을 사용하고, 외부 문서의 고유한 설명·사례·도표·편집 구성을 복제하지 않는다.

## 대체 자료와 적용 범위

**유치원 교육과정, 교육부 고시 제2019-189호, 제1장 Ⅱ 운영**의 놀이 참여·개별 특성 고려·평가 활용 원칙을 참고한다. [고시 원문](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000180641&chrClsCd=010201)

고시는 저작권법 제7조 제2호 대상이므로 고시 원문 자체에는 별도 저작권 허락·사용료가 필요하지 않다. 이 판단을 상업 해설서, 삽화, 학습지, 기관 로고, 특정 프로그램·검사 도구에 확장하지 않는다. 참고 조문과 고시 번호는 정확성 확인을 위해 표시한다. 기관의 인증이나 후원을 받은 것처럼 표시하지 않는다.

새 계획의 ‘현행수준·목표·내용·방법·평가계획’은 시행규칙에서 정한 공통 구성요소다. 누리과정 연결, 주·월 구분, 관찰 기록, 조건부 다음 계획은 케어릿 실행 도구의 입력·검토 항목으로 구성한다. 기존 UI에서 직접 만든 HTML 표와 카드, 직접 작성한 합성 자동차 놀이 예시를 사용한다. 이전 자료를 연구한 이력은 이 문서에 남기며, 깨끗한 방 방식으로 처음부터 독립 개발했거나 권리 검토/교육적 검증이 완료된 전체 서비스라고 주장하지 않는다.

법령·고시는 IEP 구성과 교육과정 운영의 근거다. 특정 활동의 효과·적정 빈도·성공률·장애별 중재 효과를 증명하는 근거가 아니다. 이 범위로는 계획 정리·초안 작성을 지원하며, 자동으로 검증된 중재 활동을 추천한다고 표시하지 않는다. 새로운 활동 근거가 필요하면 별도 이용조건이 확인된 자료를 추가로 채택한다.

특수교육 교육과정 고시에도 2026년 개정이 확인됐다([국가교육위원회 고시 제2026-2호](https://www.law.go.kr/LSW/admRulInfoP.do?admRulSeq=2100000273518)). 개정 별책 전체를 이번 기능의 교수 방법 근거로 사용한 것은 아니다. 향후 특수교육 교육과정 연결을 자동화할 때 적용 학년·시행일과 해당 별책을 먼저 확인한다.

## 실제 AI 연결 시

- 현재 목업은 AI 호출, PDF 수집, 검색용 자료 저장소(RAG), 모델 학습을 하지 않는다.
- 이번 채택 범위의 법령·고시 원문과 자체 작성 규칙만으로 시작한다. 외부 책 전체를 업로드하거나 금지 자료의 요약·번역을 우회용 입력으로 만들지 않는다.
- 자료를 추가할 때 정확한 파일/버전, 권리자, 상업 이용, 변경, AI에 제공·저장할 범위, 출처 표시와 제외된 제3자 콘텐츠를 기록한다. RAG 입력과 모델 학습은 같은 사용이라고 가정하지 않는다.
- [공공누리 제1유형](https://www.kogl.or.kr/info/licenseType1.do)은 해당 저작물에 실제로 적용되면 출처 표시 등 조건에 따라 무료 상업 이용·변경이 가능하다. 현재 보류한 해설서에 이 유형이 적용된다고 확인한 것은 아니다.
- [한국저작권위원회 설명](https://www.copyright.or.kr/information-materials/common-sense/knowledge-for-netizen/index.do)처럼 아이디어와 표현을 구분한다. 출처 표시만으로 금지된 이용이 허용되지는 않으며, 문장 치환 비율 같은 기준도 사용하지 않는다.

## 기존 계획 및 목업 반영

- 신규 결과는 `sourcePolicy: law-own-2026-09-23`, 출처 ID `iep`, `nuri`, `own`만 가진다.
- 이전 저장본의 내용·검토 상태·저장 ID·당시 출처 ID는 유지한다. 새 근거로 검증한 계획처럼 바꾸지 않는다.
- 이전 출처의 원문 요약은 런타임에서 제거하고, 제목·이전 참고 이력·신규 제외 사유만 둔다.
- 이전 계획을 입력 화면에서 재구성하면 새 기준을 사용한다. 직접 편집한 연결 문장 등을 보존할 경우 `previousSourceIds`를 남긴다. 이것이 보존된 문장에 새 이용허락을 부여하지는 않는다.
- 근거 목록·팝업·계획서 다운로드에도 현재 근거와 이전 참고 이력을 구별한다.
- 기존 브라우저 저장본이나 사용자가 따로 내려받은 과거 HTML까지 소급하여 제거하거나 이용 권한이 확인됐다고 표시하지 않는다.

## 비용이라는 말의 의미

검증·전문가 검토·업데이트는 자료 사용료나 생성 건별 의무 납부 비용이 아니다. 작업을 내부에서 하면 내부 인력·시간, 외주로 맡기면 합의한 용역비가 된다. 자동 청구나 계약을 발생시키지 않았다.

- 자료 검증: 맞는 문서·버전인지, 이용조건과 출처가 맞는지 확인하는 작업. 이번에 진행한 확인이 이에 해당한다.
- 전문가 검토: 자체 예시와 AI 출력이 유아특수교육 현장에서 적절한지 유아특수교사가 표본을 검토하는 작업. 외부 전문가를 꼭 유료로 고용해야 한다는 뜻이 아니다. 내부 검토자가 있으면 내부에서 진행할 수 있다.
- 업데이트: 법령·교육과정·자료가 개정될 때 관련 규칙과 링크를 고치는 유지보수 작업. 매월 자료비를 내야 한다는 뜻이 아니다.

선택한 법령·고시 원문에는 별도 저작권 이용료를 편성하지 않는다. 비용 없는 자료를 선택해도 개발·운영에 드는 시간은 남지만, 이를 임의의 원/명 단가로 더하지 않는다. 종전 109원 등의 수치는 당시 가정한 AI 호출량의 비용이며 전체 사업 원가나 확정 견적이 아니다.
