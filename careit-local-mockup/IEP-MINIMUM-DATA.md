# IEP 대상 정보 최소 수집 설계

2026-09-23 · 월간 실행계획 작성 지원 목업에 적용한 범위

## 대상 등록

새로 입력받는 항목은 **구분명(별칭 허용)**과 **연령대** 두 개입니다. 내부 등록일·활성 상태·기록 연결 정보는 서비스 동작용으로 유지합니다.

- 구분명: 대상 목록과 내려받는 문서의 표시 이름. 실명을 요구하지 않습니다.
- 연령대: 고정 선택지. 만 3세 미만, 만 3세, 만 4세, 만 5세, 만 6~7세, 만 8~12세, 만 13~17세, 만 18세 이상.
- 정확한 생년월일, 성별, 주소, 주민등록번호, 보호자 연락처, 사진, 진단명 입력란을 추가하지 않습니다.
- 대상 등록의 자유 메모 입력란을 제거했습니다. 기존에 작성한 메모는 상세의 ‘기존 메모’에서만 보여 주고 덮어쓰거나 삭제하지 않습니다.
- 기존 대상의 연령대는 추정하지 않습니다. 등록 정보 수정 또는 새 IEP 초안 구성 시 사용자가 선택합니다.

## 계획을 작성할 때만 받는 정보

교사가 적는 필수 내용은 월 목표와 목표에 관련된 현재 수행 모습 두 가지입니다. 활동·자료·교사 지원·평가계획은 초안에서 제안하며, 생성 전에 입력하도록 요구하지 않습니다. 기간은 계획 운영에 필요합니다. 전체 발달 영역이나 병력을 모두 입력하도록 요구하지 않습니다.

흥미·강점과 기존 IEP 목표는 선택 입력입니다. ‘목표에 필요한 추가 정보 · 선택’을 펼치면 다음 두 항목을 작성할 수 있습니다.

| 항목 | 작성 범위 |
|---|---|
| 보호자의 교육적 요청 | 목표·지원에 반영할 요청. 보호자 이름·연락처·가족사는 제외 |
| 활동 참여·안전에 필요한 지원 | 활동에서 필요한 조치. 상세 병력·진단서·검사보고서는 제외 |

이 두 항목은 비워도 계획 구성·저장이 가능합니다. 입력한 항목만 결과 카드와 계획서 표에 표시합니다. 관찰 결과는 활동 후 작성하며 미리 생성하지 않습니다. 원문 문서 업로드 기능은 추가하지 않았습니다.

## 계획 구성용 입력과 화면 표시 정보 분리

`iep.js`의 `planningInput()`은 `PLANNING_LABELS`에 정의된 필드와 월 기간만 새 객체로 구성합니다. 생성 결과도 이 객체를 입력으로 사용합니다.

- 포함: 연령대, 월 기간, 기존 IEP 목표·월 목표, 현재 수행 모습, 선택한 흥미·교육 요청·참여 지원.
- 활동·자료·교사 지원·누리과정 연결·평가계획은 결과이며 최초 제안 입력에는 포함하지 않습니다. 결과 직접 수정은 보존합니다. 이전 양식의 3~6번 입력은 `result.legacyInput`에 복구용으로만 보관하며 생성 입력이나 계획서에는 싣지 않습니다.
- 제외: 대상 구분명, 대상 인덱스, 기존 대상 메모, 일지 원문, 계정·기관·연락처 정보, 알 수 없는 추가 필드.
- 화면과 내려받는 문서에서는 대상을 구분하기 위해 구분명을 별도로 표시합니다. 계획서 파일명에는 구분명을 넣지 않습니다.
- 입력 범위 확인 버튼·팝업은 화면에서 제거했습니다. 생성 입력 허용 목록은 유지합니다.
- 직접 입력한 문장의 실명·연락처까지 자동 익명화하는 기능은 없습니다. 이름을 쓰지 않아도 기록이 특정 대상과 연결되면 개인정보일 수 있습니다.

목업은 AI·외부 API에 전송하지 않습니다. 향후 AI 구현은 이 허용 목록을 경계로 사용하고, 전체 상태나 원문 일지를 전송하지 않도록 해야 합니다. 입력 안내만으로 개인정보 보호가 완료되는 것은 아니며, 실제 운영의 처리 근거·동의, 접근 권한, AI 공급자 설정, 보유·삭제 기간은 별도 구현 범위입니다.

## 기존 데이터와 호환

- `recipients[].name` 필드는 이름을 바꾸지 않고 구분명으로 사용합니다. 대상 배열 인덱스도 유지하므로 기존 일지·계획 연결이 바뀌지 않습니다.
- 연령대는 `recipients[].ageBand`, 계획 당시 값은 `result.input.ageBand`에 저장합니다. 과거 저장본의 값을 현재 나이로 자동 갱신하지 않습니다.
- 현재 `schemaVersion:4`는 월간 계획만 사용합니다. 기존 v2/v3의 공통 필드 직접 편집·검토 상태·저장 ID는 유지합니다. v1은 기존과 같이 7개 양식 항목을 검토하도록 전환합니다.
- 전환 전 초안·저장본은 로컬 `state.iep.monthlyArchive`에 1회 보존합니다. 주 기간·주 목표는 활성 입력에서 제외합니다. 이 보관 데이터는 계획 구성 입력이나 개별 계획서에 포함하지 않으며, 전체 목업 내보내기에만 함께 보관합니다.
- ‘입력 수정 → 변경 내용 반영’은 현재 연령대·입력으로 초안을 갱신하며 직접 수정한 연결 문장을 유지합니다.

## 검수

- 구분명만 입력하면 연령대 선택 안내, 두 항목 입력 후 등록 성공
- 기존 대상 연령대 수정, 기존 메모·계획 연결·직접 편집 문장 유지
- 선택 정보 없이 초안 구성, 선택 지원 입력 후 결과·표 반영 및 새로고침 복원
- 구분명·메모·생년월일·일지 원문과 미등록 필드가 계획 입력에 포함되지 않는 허용 목록 검사
- 390px 등록 폼 세로 배치 및 가로 넘침 없음

검수용 데이터와 스크립트는 `_qa/`에 있으며 전달 ZIP에는 포함하지 않습니다.
