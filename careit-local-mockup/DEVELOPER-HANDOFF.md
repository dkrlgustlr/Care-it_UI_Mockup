# 케어릿 UI/UX 변경사항 — 개발자 전달본

기준일: 2026-09-23 · 기존 UI 기준 코드: `cf8aae8` · IEP 월간 실행 계획 포함

## 추가: IEP 월간 실행 계획

- 사이드바 일지 작성 아래에 IEP(`/iep`)를 추가했습니다. 기존 색상·회색 입력칸·배지·그림자·본문 폭을 공유합니다.
- 목표 입력 → 계획 검토 → 교사 검토 후 저장 흐름입니다. 월 기간, 월 목표, 현재 관찰, 흥미·강점, 활동·자료, 지원, 평가 방법을 입력합니다.
- 결과에는 월 목표 연결, 활동 준비·지원·관찰, 다음 달 검토, 빈 관찰 기록 틀이 있습니다. 직접 편집, 입력 수정 반영, 대상별 저장·다시 열기, 표 형태의 HTML 계획서 내려받기가 동작합니다.
- 구성 근거는 법령·고시 원문과 자체 규칙으로 제한하며, 출처 정보는 내부 문서에 보관합니다. 화면에서는 출처·단계 안내를 제거했습니다.
- `iep.js`/`iep.css`가 기능을 담당하고 `mockup.js`의 공통 달력을 재사용합니다. `build.py`가 전달 HTML에 모두 내장합니다. `state.iep`의 초안·저장 계획도 수정본 HTML 내보내기에 포함됩니다.
- 실제 AI·RAG·일지 분석은 미연결입니다. 합성 예시와 교사 입력에 고정된 원칙을 연결하는 목업이며, 교육적 적합성 판단과 공식 IEP 확정은 자동화하지 않습니다.

아래 웹 링크와 로컬 `careit-mockup.html`에서 IEP가 포함된 최신 결과를 확인할 수 있습니다.

- [최종 목업 보기](https://dkrlgustlr.github.io/Care-it_UI_Mockup/careit-local-mockup/careit-mockup.html)
- [목업 소스](https://github.com/dkrlgustlr/Care-it_UI_Mockup/tree/main/careit-local-mockup)

아래 내용은 작업 중간안이 아니라 최종 적용 상태입니다. 기존 서비스 화면을 바탕으로 만든 HTML 목업이며, 실제 서비스 배포와 API 연결은 별도입니다.

## 1. 공통 레이아웃과 문구

| 항목 | 최종 변경사항 |
|---|---|
| 주요 화면 본문 폭 | 일지 작성도 다른 주요 화면과 같은 최대 너비 사용. 기본 `1120px`, 뷰포트 너비 `1440px` 이상에서 `1280px`. |
| 설정 화면 폭 | 설정 화면은 기존 최대 `680px` 유지. |
| 하단 회사 정보 | 하단 구분선과 회사 정보의 좌우 경계를 해당 화면 본문과 동일하게 정렬. 설정 화면에서는 하단도 설정 본문 폭에 맞춤. |
| 페이지 제목 아래 설명 | 주요 탭의 페이지 제목 바로 아래 붙던 소개·설명 문구 삭제. 페이지 제목은 유지. |

페이지 소개 문구만 삭제한 것이므로 입력 도움말, 오류·빈 상태 안내, 생성 조건, 팝업 설명 등 기능에 필요한 문구는 유지합니다. 홈의 날짜 표시도 유지합니다.

## 2. 공통 색상·그림자·테두리

| 항목 | 최종 기준 |
|---|---|
| 전체 화면 배경 | 기존 `#F6F8FA` 유지. |
| 흰색 섹션 카드 | 흰색 유지. 그림자를 완전히 없애지 않고 아래 공통값으로 약하게 통일. |
| 그림자가 있는 카드·팝업·주요 버튼 | `0 4px 12px rgba(22,32,42,0.05)` 사용. hover/focus에서 다른 진하기·퍼짐의 그림자로 바뀌지 않도록 통일. |
| 회색 입력·선택 요소 | 메모칸, 입력칸, 드롭다운, 날짜 선택칸, 퀵체크 선택칸, 회색 보조 버튼, 기록/요금제 탭의 그림자 제거. 선택·hover·focus에서도 그림자가 다시 생기지 않음. |
| 회색 입력·선택칸 배경 | 기존 공통색 `#EEF3F5` 유지. |
| 모달 뒤 배경막 | `rgb(22 32 42 / 35%)`로 통일. |
| 입력 포커스 | 입력칸과 초록 포커스 테두리 사이의 흰 틈 제거. 해당 컨트롤의 `outline-offset: 0`. 초록 포커스 표시 자체는 유지. |
| 일지 저장 영역 | 하단 ‘저장 전 확인’ 흰색 섹션의 1px 외곽 테두리 제거. |
| 관리대상 카드 | 활성·비활성 관리대상 카드의 1px 외곽 테두리 제거. 비활성 상태 구분은 유지. |
| 리포트 회색 구분선 | 일부 푸른 회색 `#D9E1E5` 구분선을 기존 공통 구분선색 `#00000014`로 변경. 두께는 기존 1px 유지. |

리포트 변경 대상은 하단 페이지 정보 위 선, ‘기록 안내 · 산출 기준’ 위 선, 점수·발췌·영역 항목의 같은 역할 구분선입니다. 관련 선택자는 `.configured-report-footer`, `.configured-report-method`, `.configured-report-scores li`, `.configured-report-excerpts li`, `.configured-report-area`입니다. 흰 배경에서 공통 선은 약 `#EBEBEB`로 보입니다.

배경·입력칸·스크롤바 등 역할이 다른 회색을 모두 하나로 합친 것은 아닙니다. 글자색은 이번 회색 통일 대상에서 제외했습니다. 사이드바 경계, 문서 외곽, 인쇄 영역 등은 각 용도에 맞는 구성을 유지합니다.

## 3. 초록색 강조와 상태 배지

- ‘초안 검토’ 등 기존 파란 상태 강조를 초록색 계열로 변경했습니다.
- 초안 배지는 배경 `--mint-soft` (`#EDF8F3`), 글자 `--primary-dark` (`#06784F`)를 사용합니다.
- 텍스트 드래그 선택 영역도 `--mint-selected` (`#D1F0E0`) 배경으로 변경했습니다. 기본 컨트롤의 accent 색도 서비스 초록색을 사용합니다.
- 초안 검토, 기록 상태, 비활성화, 현재 브라우저, 요금제 배지에 공통 여백을 적용했습니다.

| 배지 속성 | 값 |
|---|---|
| 좌우 여백 | `8px` |
| 위아래 여백 | `4px` |
| 줄 높이 | `20px` |
| 최소 전체 높이 | `28px` |
| 너비/줄바꿈 | 문구 길이에 맞게 늘어나며 한 줄 유지 |

## 4. 글자 크기

| 기존 크기 | 최종 크기 |
|---|---|
| `12px`, `13px` | `14px` |
| `16px` | 유지 |
| `18px` | `20px` |
| 나머지 크기 | 유지 |

- 주요 서비스 화면의 기본 크기는 `14 / 16 / 20 / 24 / 36px`입니다.
- 리포트 문서·차트의 별도 크기 `28 / 30 / 30.8px`는 유지했습니다. 원래 16px이던 리포트 설명 제목도 16px 유지입니다.
- 팝업·달력·모바일 메뉴의 해당 크기도 동일한 치환 기준으로 반영했습니다. 모바일 입력 요소의 기존 16px은 유지합니다.
- 글꼴은 기존 Pretendard를 사용합니다.
- 목업 편집 도구의 17px 제목은 유지한 예외이며 서비스 화면 추가 요구사항은 아닙니다.

## 5. 홈

- 관리대상 카드에 표시되는 최근 일지 설명을 최대 **5줄**로 제한했습니다.
- 5줄을 초과하면 말줄임표로 표시합니다. 실제 저장 내용은 자르지 않습니다.

## 6. 일지 작성

### 상단 선택 영역

- `관리대상 → 작성 날짜 → 저장한 일지 수정` 순서를 유지합니다.
- PC에서는 세 항목을 동일 너비의 3열로 배치하고, 항목 간격을 조정해 ‘저장한 일지 수정’ 제목이 한 줄로 보이게 했습니다.
- ‘저장한 일지 수정’ **제목 옆 접기/펼치기 화살표와 해당 접기 기능을 제거**했습니다. 기록 선택 컨트롤은 항상 표시합니다.
- 기록 선택 드롭다운의 열기/닫기와 컨트롤 안쪽 화살표는 유지합니다.
- 모바일에서는 세 항목을 세로로 배치합니다.
- 저장 일지 목록 팝업은 **최대 높이 350px**, 초과 항목은 팝업 내부 스크롤로 확인합니다. 화면 공간이 부족하면 더 낮게 제한합니다.

### 메모 제목과 편집 상태

자유 메모, 사회·정서, 학습·활동, 건강·안전, 특이사항 제목에 공통 적용했습니다.

| 상태 | 최종 표현 |
|---|---|
| 평소 | 제목의 회색 입력 박스를 없애고 흰 카드 위에 배경 없는 텍스트로 표시. 제목 왼쪽은 아래 메모칸 바깥 왼쪽 경계와 정렬. |
| 편집 가능 표시 | 제목 옆 회색 연필 아이콘. 기존 아이콘과 같은 `--muted` 색상 사용. |
| 편집 진입 | 제목 또는 연필을 누르면 제목 입력에 초점이 이동하고 편집 상태 표시. |
| 편집 중 | 아래 메모칸과 같은 회색 `#EEF3F5` 배경과 둥근 모서리. 제목 글자는 메모칸 내부 여백과 같은 16px 들여쓰기. 연필은 초록색. |
| 편집 종료 | Enter 또는 바깥 클릭으로 초점이 빠지면 배경과 들여쓰기를 없애 평소 정렬로 복귀. 한글 조합 중 Enter는 조합 확정에 사용. |

- 연필은 무료 **Lucide Pencil** 공식 SVG를 사용합니다. SVG와 ISC 라이선스를 소스에 포함했습니다.
- 편집 중 민트 배경과 아래 가로선은 최종안에서 제거했습니다. 밑줄·그림자도 없습니다.
- 제목 위의 `n/12자` 카운터는 삭제했습니다. **제목 최대 12자 제한은 유지**합니다.
- 메모 본문의 `n/300자`, `n/500자` 카운터와 제한은 유지합니다. 다른 설정 입력의 카운터를 일괄 삭제한 것은 아닙니다.

### 메모 섹션과 저장 영역

- ‘오늘의 메모’ 섹션 제목과 ‘제목 변경은 현재 열린 일지와 이후 새 일지에 적용돼요…’ 설명 문구를 화면에서 제거했습니다.
- 첫 메모 제목에 남아 있던 추가 상단 24px 여백을 제거해 카드 위·아래 여백을 맞췄습니다. 카드 자체의 반응형 안쪽 여백은 유지합니다.
- 하단 ‘저장 전 확인’ 영역도 일지 본문과 동일한 너비를 사용하고 외곽 1px 테두리를 제거했습니다.

### 퀵체크

- 아침·점심·저녁 식사의 `도시락/기타`를 **`도시락`**으로 변경했습니다.
- 선택해도 주관식 입력이 열리지 않는 기존 선택형 항목에서 ‘기타’라는 표현만 제거한 변경입니다.
- 주관식 입력을 새로 추가한 것은 아닙니다. 별도 퀵체크 편집의 텍스트 유형은 유지합니다.
- 선택칸 그림자는 제거하고 항목 간 간격을 `8px`로 맞췄습니다. 선택 시 연한 초록 배경은 유지합니다.
- 퀵체크 섹션의 접기/펼치기는 유지합니다.

## 7. 기록: 날짜 범위 선택

- 별도의 시작일·종료일 컨트롤을 **‘날짜’ 버튼 하나**로 합쳤습니다.
- 최종 필터 순서는 **`날짜 → 관리대상`**입니다. ‘시작일 → 종료일 → 관리대상’은 중간안입니다.
- 날짜 버튼에서 하나의 달력을 열고 시작일, 종료일 순서로 선택합니다.

| 상황 | 동작 |
|---|---|
| 첫 날짜 클릭 | 시작일 선택 후 종료일 선택 단계로 전환 |
| 두 번째 날짜 클릭 | 종료일 확정, 기간 적용, 달력 닫기 |
| 같은 날짜 두 번 클릭 | 하루 범위로 적용 |
| 시작일보다 이른 날짜 클릭 | 그 날짜를 새 시작일로 설정하고 종료일 선택 대기 |
| 종료일 확정 전 바깥 클릭/Esc | 이번 선택을 적용하지 않고 기존 기간 유지 |
| 월 이동 | 다른 달에 걸친 기간 선택 가능 |
| 날짜 지우기/기간 초기화 | 선택 기간 해제 |
| 관리대상·기록 종류 변경 | 선택 기간 유지 |

- 시작일·종료일은 진한 초록색, 중간 기간은 연한 초록색으로 표시합니다.
- 마우스 이동과 키보드 이동으로 선택 예정 범위를 미리 보여줍니다.
- 기록의 날짜 필터 기준은 일지 작성일, 리포트 생성일, 휴지통 삭제일입니다.
- 일지 작성 화면의 ‘작성 날짜’는 단일 날짜 선택을 유지합니다.

## 8. 리포트: 기간 선택과 구분선

- ‘리포트 기간’의 기존 드롭다운을 기록 화면과 같은 **시작일 → 종료일 기간 달력**으로 변경했습니다.
- 기록 조회 기간과 리포트 생성 기간은 서로 별도로 관리합니다.
- 종료일 확정 전 취소하면 기존 기간을 유지하고, 날짜를 지우면 리포트 생성 버튼을 비활성화합니다.
- 선택 대상·기간의 서로 다른 저장 일지 날짜 수를 계산하고 기존 생성 기준인 3일 충족 여부를 표시합니다. 3일 기준 자체를 새로 변경한 것은 아닙니다.
- 일부 리포트 구분선의 색상 차이는 2번 공통 규칙에 맞춰 통일했습니다.

## 9. 관리대상 상세 팝업

- 상단 ‘○○ 상세’ 제목의 왼쪽과 ‘닫기’ 버튼의 오른쪽을 아래 본문 내용의 좌우 경계에 맞췄습니다.
- 본문 스크롤바가 생겨도 헤더와 본문 정렬이 어긋나지 않게 여유 공간을 맞췄습니다.
- 헤더 바로 아래 가로선의 최종값은 **공통 회색 `#00000014`, 1px**입니다.
- 작업 중 적용했던 초록색 2~3px 선은 취소한 안입니다.

## 14. IEP 실행 계획 양식

- 현재 기준: 특수교육법 시행규칙 제4조와 유치원 교육과정 고시의 기본 원칙을 참고한 자체 실행 양식. 인적사항·지원팀 등 학교의 공식 IEP 전체는 범위에 포함하지 않습니다.
- 입력·결과 순서: 현행수준 → 교육목표 → 관련 누리과정 → 교육내용 → 교육방법 → 평가계획 → 평가결과.
- 교육목표는 기존 학기/장기 IEP 목표에 월·주 실행 목표를 연결합니다. 장·단기를 주·월과 일대일로 간주하지 않습니다.
- 교육방법을 준비·환경, 진행 순서, 교사의 지원, 반응별 지원으로 구분합니다. 평가방법과 평가초점을 나누고 실제 평가결과는 관찰 후 직접 입력합니다.
- 관련 누리과정과 관찰 결과를 임의로 채우지 않습니다. 관찰 전 평가결과가 빈 상태로도 저장할 수 있습니다.
- 기존 카드·입력칸·초록 강조·글자 크기 토큰을 재사용합니다. 결과의 항목 바로가기, 카드/표 전환, 표 형식 HTML 문서 내려받기를 지원합니다.
- `iep.js`에서 입력과 결과를 관리하고 `iep.css`에 스타일을 모았습니다. `build.py`가 이 둘도 단일 HTML에 포함합니다. 세부 확인은 `IEP-REVIEW.md`를 참고하세요.
- `state.iep`에 대상별 초안과 저장본이 있습니다. 이전 결과는 필드 키로 7개 섹션에 재배치하고 새 필드를 추가합니다(`schemaVersion:2`). 기존 문장·편집 표시·저장 ID는 유지합니다. 새 항목 검토가 필요하므로 검토 완료 상태는 해제합니다.
- 실제 AI·RAG·서버 저장은 없습니다. 고정된 원칙과 교사 입력으로 계획 틀을 구성하는 목업입니다. 상세 자동차 사례는 동일한 목표·관찰·활동·지원 입력일 때만 적용합니다.

## 15. 대상 정보 최소 수집

- 대상 등록/수정은 구분명·연령대 두 항목으로 줄였습니다. 구분명은 별칭을 허용하고 생년월일 입력은 없습니다. 연령대는 기존 공통 드롭다운으로 선택합니다.
- 신규 등록용 자유 메모는 제거했습니다. 기존 메모는 읽기 전용으로 보존하며 IEP에 자동 활용하지 않습니다.
- IEP 관찰은 해당 목표와 관련된 행동·도움 정도만 요청합니다. 보호자 교육 요청·활동 참여/안전 지원은 접힌 선택 영역에서 입력합니다.
- 계획 구성 함수는 허용 목록으로 입력을 새로 구성합니다. 대상 구분명·식별 인덱스·계정 정보·기존 메모·일지 원문은 전달 객체에 넣지 않습니다. 화면 표시와 계획서의 구분명은 별도로 붙입니다.
- 연령대·선택 항목 추가 당시 버전은 `schemaVersion:3`이며 v2 계획의 편집 내용·검토 상태·저장 ID를 보존합니다. 기존 대상 연령대는 임의로 추정하지 않습니다.
- 자동 개인정보 마스킹이나 실제 AI 전송은 구현하지 않았습니다. 상세 데이터 항목, 이동 경계와 운영 구현 시 확인할 범위는 `IEP-MINIMUM-DATA.md`에 정리했습니다.


## 16. IEP 자료 사용 범위 조정

- 신규 계획 구성 근거는 `iep`, `nuri`, `own`만 사용합니다. 인천교육청 양식·총론 해설서·DEC는 신규 구성에서 제외합니다.
- `sourcePolicy`로 현재 기준을 구별합니다. 기존 계획의 문장·확정 상태·출처 ID는 변경하지 않으며 참고 이력은 내부 데이터로 보존합니다. 직접 편집한 문장을 새 결과에 보존하면 `previousSourceIds`도 남깁니다.
- 근거 팝업·카드·다운로드 문서에 같은 구분을 적용했습니다. 자체 예시를 공인되거나 효과 검증된 활동으로 표시하지 않습니다.
- 이용조건의 확인 근거와 상업 이용 범위, AI 연결 시 채택 기준은 `IEP-SOURCE-LICENSES.md`에 있습니다. 신규 이용료 지출이나 권리자 연락은 하지 않았습니다.

## 2026-09-23 IEP 월간 계획으로 단순화

- 상단은 관리대상 / 연령대 / 월 계획 기간이며, 공통 범위 달력에서 같은 달 안의 시작일·종료일을 선택합니다.
- 주 기간·주 목표·주간 검증을 제거했습니다. 월 목표만으로 초안 생성·저장이 가능하며, 활동·관찰·다음 달 계획으로 연결합니다.

## 2026-09-23 IEP 교사 입력 / 제안 역할 분리

- 작성 폼은 1. 현행수준, 2. 교육목표만 남겼습니다. 현재 수행 모습·월 목표만 필수이며 흥미·강점, 기존 IEP 목표와 추가 지원 정보는 선택입니다.

- IEP 현행수준·교육목표 입력은 같은 2열 배치와 3행 입력칸으로 통일했습니다. 필수 항목은 왼쪽, 선택 항목은 오른쪽이며 767px 이하에서는 같은 순서로 1열 표시합니다.
