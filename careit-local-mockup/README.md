# 케어릿 UI/UX 로컬 목업

2026년 9월 23일 https://app.careit.kr/의 로그인된 화면을 기준으로 제작했습니다.
원본 CSS, Pretendard 폰트, 로고를 로컬에 포함했습니다. 기존 프로젝트 파일은 수정하지 않았습니다.

## 웹에서 보기

[케어릿 UI/UX 목업 열기](https://dkrlgustlr.github.io/Care-it_UI_Mockup/careit-local-mockup/careit-mockup.html)

설치나 로그인 없이 링크로 확인할 수 있습니다. 편집 내용은 각자의 브라우저에만 저장되며, 다른 사람에게 수정 내용을 전달하려면 **수정본 HTML 저장**을 사용하세요.

## 바로 열기

**`careit-mockup.html`을 더블클릭하세요.** Chrome 또는 Edge에서 열면 됩니다.
폰트·이미지·CSS·JavaScript가 이 파일 하나에 들어 있습니다. 설치, 로그인, 인터넷, 서버 실행이 필요하지 않습니다.

## 직접 수정하고 전달하기

1. 오른쪽 아래 **목업 편집**을 누릅니다.
2. **화면 문구 직접 편집**을 켠 뒤 제목, 설명, 버튼 문구 등을 클릭해 바꿉니다.
3. 색상과 카드 모서리를 조절합니다. 레이아웃은 **추가 CSS**에 적고 **CSS 적용**을 누릅니다.
4. 문구 편집을 끄면 메뉴와 버튼을 다시 클릭할 수 있습니다. Esc로도 편집을 종료합니다.
5. **수정본 HTML 저장**을 누릅니다. 내려받은 `careit-mockup-edited.html` 하나를 개발자에게 전달합니다.

편집 내용은 현재 브라우저에 자동 저장됩니다. 브라우저에 저장된 내용만으로는 전달되지 않으므로 반드시 HTML 저장을 눌러 주세요.
추가 CSS 예시:

```css
/* 홈 카드 간격 */
.recipient-home-grid { gap: 24px; }
/* 페이지 제목 */
.page-header h1 { font-size: 28px; }
/* 일지 입력 영역 */
.journal-card { padding: 32px; }
```

## 목업 범위

현재 확인한 화면 구조와 시각 스타일을 재현한 정적 프로토타입입니다. 서비스 전체 코드나 모든 데이터의 복제본은 아닙니다.
원본 서버 저장, 로그인, 계정 삭제, 결제, AI 생성은 연결하지 않았습니다. 서버 요청은 코드와 CSP에서 차단합니다.
원본에 표시된 테스트 계정과 화면 내용을 로컬 예시로 사용했습니다. 전체 기록·모든 기간의 리포트를 가져온 것은 아닙니다.
홈의 통계는 캡처 시점 값입니다. 다른 관리대상 기록은 일부 예시만 포함하며 저장된 리포트 상세는 한 사례입니다.
휴지통은 로컬 목업에서 옮긴 리포트로 동작합니다. 원본 휴지통 데이터와 약관 본문은 포함하지 않았습니다.
AI 동의 본문은 원본 계정에서 현재 다시 열 수 없어 설정 화면 안내를 바탕으로 만든 예시이며, 팝업 안에 예시임을 표시합니다. 실제 동의 등록은 하지 않습니다. AI 다듬기 결과는 입력문을 재사용하고 리포트 생성은 포함된 예시 문서를 표시합니다.
일부 통계와 기존 샘플 리포트 내용은 고정 예시이며 실제 분석 결과를 계산하지 않습니다.
PDF 버튼은 브라우저 인쇄의 PDF 저장을 사용합니다. 원본 서비스의 PDF·Word 생성기는 포함하지 않습니다.
목업 편집 버튼은 전달 작업용으로 추가한 UI입니다.

## 소스 수정

- `index.html`: 화면별 `<template>`과 공통 메뉴. HTML을 직접 수정할 수 있습니다.
- `assets/original.css`: 서비스에서 수집한 CSS. 폰트 경로만 로컬로 변경했습니다.
- `mockup.css`: 로컬 편집 도구와 동작 보완 스타일. 디자인 변경 CSS를 덧붙일 수 있습니다.
- `mockup.js`: 로컬 인터랙션과 예시 데이터.
- `build.py`: 소스를 단일 파일 `careit-mockup.html`로 묶는 스크립트. 외부 패키지 없음.

본문과 하단 회사 정보·구분선은 같은 `--content-max-width` 기준으로 좌우를 맞춥니다. 주요 화면은 최대 1120px, 화면 너비 1440px 이상에서는 최대 1280px입니다. 설정 화면은 기존 최대 680px 폭을 유지하며 하단 정보도 그 폭에 맞춥니다.

일지 제목 옆 연필 아이콘은 [Lucide Pencil](https://lucide.dev/icons/pencil)을 사용합니다. 공식 SVG를 `assets/lucide-pencil.svg`에 보관했고, `index.html`의 아이콘 template에 동일한 SVG를 포함했습니다. ISC 라이선스 전문은 `assets/LUCIDE-LICENSE.txt`와 단일 HTML 주석에 포함됩니다. 아이콘 색상은 기존 UI의 `--muted` 값을 사용합니다.

평소 제목 글자는 메모칸의 왼쪽 경계에 맞춥니다. 제목이나 연필을 누르면 메모칸과 같은 회색 배경과 둥근 모서리가 표시되고, 글자는 메모칸 내부와 동일하게 16px 들여쓰며 연필은 초록색으로 바뀝니다. 밑줄과 그림자는 없습니다. Enter 또는 바깥 클릭으로 편집 상태를 마치면 기본 정렬로 돌아갑니다. 한글 조합 중 Enter는 글자 확정에 사용합니다.

소스를 수정한 다음 이 폴더에서 `python build.py`를 실행하면 전달용 HTML이 갱신됩니다.
소스용 `index.html`도 직접 열 수 있지만 **단일 파일 내보내기는 `careit-mockup.html`에서 사용합니다.**

## 팝업 보완 사항 (2026-09-23)

- 선택창에 최소 폭을 주고 항목명 줄바꿈을 방지했습니다. 선택 표시는 원본 체크 아이콘을 사용합니다.
- 저장한 일지 수정 목록은 최대 높이 350px로 제한하고, 넘치는 기록은 목록 안에서 스크롤합니다. 화면에 공간이 부족하면 높이를 더 줄입니다.
- 팝업을 브라우저 top layer에 배치해 카드나 모달의 overflow에 잘리지 않게 했습니다. 공간이 부족하면 위로 열고 좌우 위치도 화면 안으로 조정합니다.
- 드롭다운은 방향키/Home/End/Enter/Esc, 달력은 방향키/PageUp/PageDown/Enter/Esc를 지원합니다. 닫으면 트리거로 초점을 돌립니다.
- 달력 월 이동 중 닫히던 문제, 대상 변경 시 리포트의 대상 선택이 사라지던 문제, 큰 편집창의 헤더가 스크롤되어 숨던 문제를 보완했습니다.
- 이전 요청인 일지 상단 3열 동일 너비·한 줄 제목과 투명한 메모 제목·회색 Lucide 연필은 유지했습니다.

브라우저에서 354px 모바일 화면과 1440px 데스크톱 화면을 확인했습니다. 대상 이름 한 줄 표시, 달력 월 이동·날짜 선택·기간 제한과 기록 필터, 퀵체크 추가 후 재조회, 채점 문항 저장, 모달 안 드롭다운, 변경 취소 확인, 리포트 휴지통 이동·복원을 검증했습니다. QA용 파일과 데이터는 전달 ZIP에 포함하지 않습니다.

기록 화면의 필터는 날짜 → 관리대상 순서입니다. 날짜 버튼을 누르면 하나의 달력에서 시작일과 종료일을 차례로 선택하며, 두 번째 날짜를 고르면 기간이 적용되고 달력이 닫힙니다. 시작일과 종료일은 초록색, 사이 기간은 연한 초록색으로 표시하고 마우스와 방향키로 선택할 기간을 미리 볼 수 있습니다. 종료일을 고르기 전에 달력을 닫으면 기존 기간을 유지하며, 시작일보다 이른 날짜를 누르면 그 날짜를 새 시작일로 정합니다. 같은 날을 두 번 누르면 하루만 조회합니다.

오른쪽 초기화 버튼과 달력의 날짜 지우기는 선택 기간을 지웁니다. 대상이나 기록 종류를 바꿔도 기간은 유지합니다. 날짜 필터는 일지의 작성일, 리포트의 생성일, 휴지통의 삭제일에 적용됩니다. 월을 넘기는 기간 선택·같은 날 선택·선택 취소·기간 초기화·354px 모바일 화면과 일지 작성용 단일 날짜 달력을 확인했습니다.

## 리포트 기간 달력

리포트 기간도 기록 화면과 같은 달력에서 시작일 → 종료일 순서로 선택합니다. 기록 화면의 조회 기간과는 별도로 유지하며, 선택한 관리대상의 일지에서 중복 날짜를 제외한 기록 일수를 계산해 생성 기준 3일 충족 여부를 표시합니다. 날짜를 지우면 생성을 비활성화하고, 종료일을 선택하기 전에 닫으면 기존 기간을 유지합니다.

기존 2026년 8월 28일~9월 3일 리포트 예시는 해당 기간을 선택하거나 기록 목록의 보기로 열 수 있습니다. 다른 기간은 생성 확인 대화상자까지만 시연하며, 고정 예시를 새 기간의 실제 결과로 표시하지 않습니다.

## 상태 배지 여백

초안 검토·기록 상태·비활성화·현재 브라우저·요금제 배지는 좌우 8px, 위아래 4px, 줄 높이 20px(전체 최소 높이 28px)을 공통으로 사용합니다. 여백은 `mockup.css`의 `--badge-padding-inline`, `--badge-padding-block`, `--badge-line-height`에서 함께 조정합니다. 글자 수에 따라 배지 너비가 늘어나며 한 줄을 유지합니다.

## 공통 그림자

카드·팝업 등 그림자가 있는 영역은 `mockup.css`의 `--shadow-ui: 0 4px 12px rgba(22,32,42,0.05)` 하나를 사용합니다. 마우스나 선택 상태가 바뀌어도 그림자 값은 같습니다. 회색 입력칸·선택칸·보조 버튼·탭은 그림자가 없습니다. 관리대상 외부 카드의 테두리는 제거했고, 모달 배경막은 35%로 통일했습니다.

투명한 제목·아이콘, 기본 체크 컨트롤, 비활성 버튼, 문서 내부 및 인쇄 영역은 기존의 그림자 없는 구성을 유지합니다. 세부 검수와 적용 내역은 `SHADOW-AUDIT.md`에 있습니다.
