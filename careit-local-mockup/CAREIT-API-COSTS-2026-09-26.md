# 케어릿 일지·리포트·IEP 통합 API 비용 추정

## 최신 기준: 기존 일지·리포트 원가에 IEP만 추가

사용자가 정정한 기존 계산은 **스타터 5명 전체의 일지+리포트 API 비용이 월 2,000~3,000원**이다. 이 값을 현재 예산의 기준으로 유지하며, 새 토큰 가정으로 기존 기능의 원가를 대체하지 않는다. 이 금액의 실측 여부나 세부 토큰 사용량까지 확인됐다는 뜻은 아니다.

| 항목 | 스타터 5명 전체의 월 API 비용 |
| --- | ---: |
| 기존 일지 + 리포트 | 2,000~3,000원 |
| IEP 추가: 대상별 월 1회 × 5명 × 예상 49.5원 | 247.5원 |
| **합계** | **2,247.5~3,247.5원 (약 2,250~3,250원)** |

관리대상 1명으로 나누면 월 약 450~650원이다. IEP의 49.5원은 아래 가격·토큰 가정에 따른 추가 비용 추정이며 실제 호출 측정치는 아니다. 전체 금액은 모델 API 비용이며 서버·결제 등 기타 원가는 별도다. 프로 비용은 사용자의 기존 계산값을 확인하기 전까지 이 정정만으로 확정하지 않는다.

## 참고: 다른 토큰 가정으로 계산했던 시나리오

아래의 스타터 6,210~7,728.75원 등은 사용자의 기존 비용 기준과 다른 가정으로 계산한 참고 시나리오다. 현재 기준 원가로 사용하지 않는다.

기준일 2026-09-26. 실제 API를 호출하거나 사용 로그를 측정하지 않았다. **아래 참고 시나리오만 일지·리포트·IEP 모두 Gemini 3.5 Flash Standard 텍스트 API로 처리한다고 가정**한다. 사용자의 최신 방향에 따라 IEP는 관리대상 1명당 월 1회이며, 종전 공용 월 20회·60회 안은 사용하지 않는다.

## 확인한 현행 기준과 새 계산 가정

- 현재 목업 요금제: 무료 관리대상 1명, 스타터 월 14,900원·최대 5명, 프로 월 49,900원·최대 15명. 유료 표시 금액은 부가가치세 포함이다.
- 일지: 대상별 하루 AI 다듬기 1회. 자유 메모 300자와 영역 4개 각 500자로 최대 2,300자. 직접 저장에는 모델 호출이 없다고 가정한다.
- 리포트: 주간 리포트 제공, 서로 다른 날짜의 기록 3일 이상 조건만 확인됐다. 현재 목업에는 생성 횟수나 선택 기간 길이의 비용 상한이 없다.
- 따라서 아래에서는 **주간 리포트 대상별 월 5회·회당 최대 7일 기록**을 계산용 제안 기준으로 삼는다. 기존 확정 정책이나 현재 시스템의 강제 제한이라는 뜻이 아니다. 자유 기간 전체를 허용하면 이 표는 최대 비용이 아니다.
- IEP: 대상별 월 1회. 새 결제 이용기간마다 대상 슬롯별 1회 부여하는 안으로 계산한다. 같은 이용기간의 대상 삭제·재등록·교체로 생성권을 반복 지급하지 않는다. 스타터 전체 5회, 프로 전체 15회가 최대다.
- 사용자가 요청한 재생성은 제외한다. 별도 상시 모델 검증 호출·검색 도구·첨부파일은 포함하지 않는다. 한 번의 기능 실행을 모델 호출 한 번으로 가정하며, 실제 서비스가 분할 호출한다면 총 토큰·비용을 모두 더해야 한다.

## 공식 가격과 계산식

Gemini 3.5 Flash Standard: 입력 $1.50 / 100만 토큰, 출력 **생각 토큰 포함** $9.00 / 100만 토큰. [Google 공식 가격표](https://ai.google.dev/gemini-api/docs/pricing).

환율은 예산용으로 1달러=1,500원을 사용한다. 현재 환율을 뜻하지 않는다. 무료 크레딧·캐시·계약 할인은 적용하지 않았다.

`호출 비용(원) = (입력 토큰 × 1.50 + 출력·생각 합산 토큰 × 9.00) ÷ 1,000,000 × 1,500`

| 기능 | 입력 가정 | 출력·생각 합산 가정 | 1회 비용 |
| --- | ---: | ---: | ---: |
| 일지 AI 다듬기 | 3,000토큰 | 2,000토큰 | 33.75원 |
| 주간 리포트 | 16,000토큰 | 4,000토큰 | 90원 |
| IEP 월간 계획 | 4,000토큰 | 3,000토큰 | 49.5원 |

모든 입력에는 시스템 지시·필요한 문항·자료·본문을 포함한다고 가정한다. 특히 리포트 토큰은 실측이 없어 이번에 새로 설정한 가정이다. 7일의 일지, 퀵체크, 25~59개 문항과 출력 점수·요약을 다룰 수 있다는 가정이며, 원문 분량과 출력 구조에 따라 실제로는 크게 달라질 수 있다. 글자 수를 토큰 수와 동일시하지 않는다.

## 관리대상 1명당 월 비용

| 기능 | 월 22일 일지 사용 | 월 31일 일지 사용 |
| --- | ---: | ---: |
| 일지 | 22 × 33.75 = 742.5원 | 31 × 33.75 = 1,046.25원 |
| 주간 리포트 | 5 × 90 = 450원 | 5 × 90 = 450원 |
| IEP | 1 × 49.5 = 49.5원 | 1 × 49.5 = 49.5원 |
| **합계** | **1,242원** | **1,545.75원** |

22일은 평일 중심 사용 시나리오이며 실측 평균이 아니다. 31일은 일지를 매일 사용하는 빈도 시나리오이며 토큰·재시도까지 포함한 절대 최대가 아니다. 리포트 5회는 한 달에 5개의 주간 리포트가 필요한 경우를 위해 둔 횟수 예산이다.

## 결제 사용자 1명당 월 비용

등록 가능한 대상 모두가 위 빈도로 사용하는 경우다. 사용하지 않는 대상의 생성까지 과금된다고 계산하지 않는다.

| 요금제 | 대상 수 | 일지 월 22일 기준 | 일지 월 31일 기준 |
| --- | ---: | ---: | ---: |
| 스타터 | 5명 | **6,210원** | **7,728.75원** |
| 프로 | 15명 | **18,630원** | **23,186.25원** |

실패 호출·변동 토큰에 대한 임시 원가 예비비를 20% 잡으면 스타터 약 7,452~9,274.5원, 프로 약 22,356~27,823.5원이다. **20%는 실측 재시도율이나 사용자 재생성 횟수가 아니다.** 재생성 이용량에 포함하지 않고 별도 예산 민감도로만 제시한다. 실제 장애 상황을 보장하는 최대치도 아니다.

이 금액은 모델 API 비용만이다. 서버·DB·저장소·결제수수료·세금 및 환전수수료 등은 제외했다. 유료 표시 가격에는 부가세가 포함되므로 구독료에서 위 비용만 빼서 순이익이라고 부르면 안 된다. 리포트 PDF·Word·그래프를 코드로 만들면 추가 모델 호출이 없지만, 생성·저장 서버 비용은 별도로 남는다.

## 장문 사용 민감도

일지 입력 6,000·출력/생각 4,000토큰이면 67.5원, 리포트 입력 30,000·출력/생각 8,000토큰이면 175.5원, IEP 입력 6,000·출력/생각 4,096토큰이면 68.796원이다. 전부 이 분량을 쓰고 월 31일 일지·리포트 5회·IEP 1회라면:

| 기준 | API 비용 |
| --- | ---: |
| 관리대상 1명 | 3,038.796원 |
| 스타터 5명 | **15,193.98원** |
| 프로 15명 | **45,581.94원** |

모든 사용자가 장문을 쓴다는 예측은 아니다. 입력량과 생각 토큰을 관리하지 않으면 현 구독료에서 원가가 높아질 수 있음을 보여주는 스트레스 시나리오다. 이 경우 스타터는 표시 구독료를 API 비용만으로 넘고, 프로도 부가세를 제외한 구독 매출 수준에 도달한다. 추가 재시도는 포함하지 않았다.

## 정책과 구현에 반영할 우선순위

1. **일지 비용부터 확인한다.** 월 22일 계산에서 일지가 약 60%, 리포트가 36%, IEP가 4%다. IEP 제한만으로 전체 원가를 관리할 수 없다. 일지에 불필요한 생각·상시 검증·여러 후보 생성을 붙이지 않고 전체 입력·출력 토큰을 측정한다.
2. **리포트의 기간·횟수 기준을 정한다.** 우선 대상별 월 5회·한 번에 7일 이내 기록·같은 결과 재사용을 제안한다. 날짜만 하루씩 바꾸어 반복 생성하거나 저장된 같은 기간을 새로 열 때 호출하지 않는다. 같은 대상·기간·템플릿·기록 버전의 결과는 재사용하며 변경된 기록 때문에 자동 재생성하지 않는다. 월 전체 리포트나 7일 초과 기간은 별도 분량·횟수 설계가 필요하다.
3. **IEP는 대상별 월 1회로 고친다.** 스타터 5회, 프로 15회. 기존 제안의 공용 20회·60회는 폐기한다. 직접 수정·복사·내려받기는 모델 호출이 없어야 한다.
4. **횟수와 토큰을 모두 관리한다.** 서버가 성공 생성과 진행 중 예약을 기록하고, 중복·실패·복구를 구분한다. 공급자 재시도와 내부 호출도 원가에 기록한다. 출력이 잘렸다고 자동 반복 생성하지 않는다.
5. **실제 한 번의 작업을 끝까지 계측한다.** 일지·리포트·IEP 각각의 입력/출력/생각, 내부 호출 수, 지연·실패를 기록한다. 리포트가 문항 판정과 서술 생성을 분리한다면 두 호출을 합산한다. 개인 본문을 원가 로그에 그대로 남기지는 않는다.

### 일지 모델을 바꾸는 대안은 품질 확인 후에만 적용

공식 가격의 Gemini 3.5 Flash-Lite를 일지에만 사용하고 동일한 3,000 입력·2,000 출력/생각 토큰을 가정하면 일지 1회는 8.85원이다. 리포트와 IEP는 기존 Flash 가정을 유지할 경우 전체 API 비용은 스타터 약 3,471~3,869.25원, 프로 약 10,413~11,607.75원이다. [가격 근거](https://ai.google.dev/gemini-api/docs/pricing).

이는 같은 품질·토큰 사용량을 보장하는 비교가 아니다. 실제 일지의 사실 보존·누락·민감 표현·지연 시험을 통과해야 한다. 이 계산 때문에 실제 모델을 교체하거나 목업을 수정하지 않았다.
